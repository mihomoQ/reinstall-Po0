# Debian 12 实机测试记录

测试日期：2026-10-27（Asia/Shanghai）。代码版本：`7032313790c08b28f2d29bb0251d70ee1f945789`。测试机是一个 PO0 腾讯云 KVM 实例，x86_64、BIOS、约 2 GiB 内存、20 GiB virtio 系统盘，私网 IPv4 DHCP，云侧提供公网映射。

本文不包含实例地址、MAC、实例标识、公钥内容或原始日志。

## 结果

**Debian 12 → Debian 12 的完整重装通过。** 不仅运行了准备脚本，还实际启动安装器、重新分区和安装系统，最后从新磁盘系统启动并通过原公钥登录 SSH。

1. 在面板 Debian 12 中运行完整 bundle，使用 `--hold 1`。验证生成的内核/initrd、GRUB 一次性启动项、内网源参数、本地 preseed 和登录公钥。
2. 重启到 Debian Installer。原系统网卡名称与安装器名称不同，仍通过 MAC 正确识别；DHCP、网关和 DNS 正常，SSH 22 公钥登录成功。`auto-install/enable=false`、`partman/early_command` 为空，确认暂停在自动分区之前。
3. 重启回原系统。一次性启动项已消耗，原系统盘仍正常可用。
4. 在用户明确授权清空测试盘后，使用同一 bundle 准备 `--hold 2`，重启执行完整安装。
5. 安装器读取本地 preseed，从内网源下载安装组件及软件包，重新分区、安装基础系统、SSH、内核和 GRUB，执行 late_command。22:03:56 显示 Installation complete 并暂停；该次安装器菜单开始于 22:00:47。
6. 检查目标系统的网络、公钥权限、启用的服务和 GRUB 语法后，在安装器中选择 Continue，执行剩余清理并启动新系统。
7. 新系统 SSH 登录成功，实际执行 `apt-get update` 成功，三个源的 InRelease 均可获取，没有失败的 systemd 单元或 dpkg 未完成状态。

## 实机发现并修正的问题

- 主镜像参数已正确映射，但 `extra_deb_mirror` 最初仍传递上游地址。修正 `build_extra_cmdline` 的映射，并补充针对整个命令行的断言，重新准备后再进入安装器。
- 从 Windows 复制的公钥文件带 CRLF，原代码保留了行尾 CR。现在在校验和写入公钥前调用 `del_cr`，安装器和新系统都使用规范化后的公钥。

- 初次完整重装时未包含 NTP 客户端，`CanNTP=no`、`NTPSynchronized=no`。当日后续已按用户要求补充 chrony，结果见下节。

- 原始准备 trace、安装器 syslog 和机器检查记录仅保存在本地，不随公开仓库或 bundle 发布。

## 当日增补：chrony 与腾讯内网时间源

使用新增的 `po0-chrony.sh`，在上述已经重装完成的 Debian 12 上真实安装 chrony `4.3-2+deb12u3`，仅新增一个包（包管理器显示新增磁盘占用约 654 kB）。这次验证未再次清盘，也未声称新的 preseed 路径已重新完成整机安装。

同一个 helper 用于安装器目标根目录和此次运行中的根目录：保留 chrony 的发行版默认状态文件、日志和密钥路径；移除默认公网池、动态/包含文件引入的时间源；写入 `time1` 至 `time5.tencentyun.com` 的 `server ... iburst`，设置 `makestep 1.0 3`、`rtcsync`，启用对应服务。helper 只启用服务，不在安装 chroot 内启动守护进程；本次 live test 在 helper 完成后单独启动服务。

验证结果：

- `chronyd -p` 成功解析配置，只有五个腾讯内网 NTP 源。
- 五个域名解析到 `169.254.0.79` 至 `169.254.0.83`，均有成功回应；采样时选择了 `169.254.0.81`。
- `chronyc waitsync` 成功；`Leap status: Normal`。
- chrony 服务为 `enabled`、`active`；`NTP=yes`、`NTPSynchronized=yes`。
- DNS 保持 DHCP 提供的 `183.60.83.19`、`183.60.82.98`，未改为公共 DNS。
- 实际内核命令行保留 `console=ttyS0,115200n8 console=tty0`；未复制面板镜像的 CPU 调优参数。

新增隔离测试覆盖 Debian/RPM/Alpine 配置路径和服务名称、排除隐式时间源、配置幂等、包安装失败时停止、先安装再配置、只启用不启动服务，以及安装环境校时的 30 秒上限。其余发行版尚无 chrony 实机结果。
